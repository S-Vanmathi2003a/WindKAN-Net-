WindKAN-Net

Project Title

WindKAN-Net: A Kolmogorov-Arnold Network-Based Adaptive Functional Learning Framework for Wind Power Forecasting and Microgrid Energy Optimization

Project Overview

WindKAN-Net is a research project focused on wind power forecasting and microgrid energy optimization using Kolmogorov-Arnold Networks (KAN).

Objectives

- To develop an adaptive learning framework for wind power forecasting.
- To analyze wind turbine data.
- To improve forecasting performance.
- To support microgrid energy optimization.

Project Files

- "codenew1.py" – Python source code
- "Turbine_Data.csv" – Wind turbine dataset
- "README.md" – Project documentation

Technologies Used

- Python
- Machine Learning
- Kolmogorov-Arnold Networks (KAN)
- Data Analysis

Project Domain

Artificial Intelligence | Machine Learning | Renewable Energy
